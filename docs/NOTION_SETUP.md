# Setup do Notion

## Tabelas esperadas

Crie uma base no Notion com os campos abaixo:

- `Código do Frasco` como Title
- `Data da Medição` como Date
- `Espécie` como Select
- `Tratamento` como Select
- `Peso Úmido (g)` como Number
- `Fv/Fm` como Number
- `Salinidade` como Number
- `Temperatura` como Number
- `Observações` como Rich text
- `Responsável` como Rich text

## Variáveis

- `NOTION_TOKEN`
- `NOTION_DATABASE_ID`
