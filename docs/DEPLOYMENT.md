# Deploy

## Render

1. Crie um Web Service apontando para `backend/`.
2. Build Command: `npm install`
3. Start Command: `npm start`
4. Defina `NOTION_TOKEN`, `NOTION_DATABASE_ID` e, se necessário, `CORS_ORIGIN`.

## GitHub Pages

1. Publique a branch `main`.
2. Use a raiz do repositório.
3. O `index.html` funciona como hub entre o frontend principal e o app.

## Frontend

O app atual pode apontar para a API do Render via uma URL base configurada no cliente.
